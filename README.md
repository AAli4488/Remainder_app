🐰 Bunny Reminders
A cute, pastel desktop-style task reminder built with plain HTML, CSS and JavaScript in a single file.

Features
Add tasks with a date and time (6:00 AM – 11:59 PM)
Repeat tasks daily or weekly
Full-screen bunny popup with chime when a task is due
The popup stays until you click Mark as completed
Photo proof page: a task is only completed after you submit a photo
Completed tab with proof thumbnails
Tasks and photos are saved locally in your browser (nothing is uploaded)
How to use
Download bunny_reminders.html.
Open it in Chrome or Edge.
Optional (Windows): create a shortcut that opens it as an app window, then place it in shell:startup so it starts with your laptop:
   "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe" --app="file:///C:/path/to/bunny_reminders.html"
Built with
HTML + CSS (grid background, stamp frame, animations, backdrop blur)
JavaScript: localStorage, setInterval, Canvas (photo resizing), Web Audio (chime), Notifications API
Google Fonts: Quicksand and Gaegu
Notes
The reminder only fires while the app window is open.
Clearing browser site data deletes saved tasks and photos.
